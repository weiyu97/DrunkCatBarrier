# 醉猫结界（DrunkCat Barrier）

> 清醒时不必记得开，醉酒时自动帮你锁。

一个纯安卓、本地运行的开源「酒后防冲动 / 防社死系统」。**后台自动检测醉酒风险，达到阈值后自动上锁**——用户无需任何操作。打开被封印的应用需通过清醒验证。

---

## 为什么做这个

酒精损害前额叶皮层，导致抑制控制下降：

- 深夜给前任发消息
- 社交平台发布不当内容
- 冲动消费、乱转账
- 打「长电话」

**现有方案的根本缺陷**：iOS 的 SafeDrunk、Drunk Lock 等都要求用户**提前手动开启**——但真正喝多的人根本不会去开，也操作不了。

**醉猫结界的解法**：后台持续监测行为信号，一旦风险分超阈值，自动上锁。全程用户无需操作。

---

## 核心机制

```
后台监测 → 风险分累积 → 超阈值 → 30秒预警
   → 用户无操作 → 自动上锁
   → 打开被锁App → 弹清醒验证
   → 通过 → 临时放行 / 失败 → 挡回
```

### 风险信号（加权评分）

| 信号 | 权重 |
|---|---|
| 深夜时段（22:00–06:00） | 30 |
| 10 分钟内切换应用 ≥15 次 | 25 |
| 打开通讯录/短信/社交/支付类应用 | 20 |
| 加速度计持续晃动 | 15 |
| 深夜刷短视频（抖音/快手/视频号等） | 60（单条即触发） |
| 手机静置 + 长时间同一 App 前台 | 15 |
| 长时间无操作后突然活跃 | 10 |
| 打字行为异常（删除率高） | 10 |

总分 ≥ 60 → 进入 30 秒预警。**深夜打开抖音/快手等短视频，单条即达阈值，立即进入预警**（应对「手机支架刷视频 + 语音」这类不切屏、不打字的漏判场景）。

### 清醒验证（三选二随机组合）

| 题型 | 内容 |
|---|---|
| 算术选择题 | 两位数加减乘除，5 题 4 选 1，限时 15 秒 |
| 成语填空 | 挖去一字，4 个候选字 |
| 点阵记忆 | 3×3 点亮 4 格，按序还原 |

答错 2 题立即失败，失败冷却阶梯：30 秒 → 2 分钟 → 10 分钟 → 30 分钟 → 锁定至次日。

## 三种运行模式

### 无障碍拦截（主力，无需特殊条件）

监听前台应用，检测到被封印的应用被打开时弹出清醒验证。

- 门槛最低：设置 → 无障碍 → 开启
- **能拦截主用户内的所有应用**（微信、支付宝、抖音等）
- 这是绝大多数用户的主力方案

### Device Owner（可选，最强）

锁定主用户全部应用：LockTask 模式、隐藏应用、禁用安全模式、天然防卸载。

**前置条件**：设备无任何账户，无次要用户。适合备用机或新机。

```bash
adb shell dpm set-device-owner com.drunkcat.barrier/.admin.DrunkCatAdminReceiver
```

### Profile Owner（特定场景）

一键创建工作资料，无需电脑。但工作资料是独立空间（User 10），
**管不到主用户的应用**。仅适用于主动隔离应用的场景。

开启：设置 → 无障碍 → 醉猫结界 → 开启

## 构建

### 环境

- JDK 17
- Android SDK（build-tools 35，platform 35）
- Gradle 8.7

### 命令

```bash
gradle :app:assembleDebug      # 构建 debug
gradle :app:assembleRelease    # 构建 release（需 release.jks）
gradle :app:testDebugUnitTest  # 运行单元测试
```

### 签名

Release 构建需在项目根目录放置 `release.jks`。生成方式：

```bash
keytool -genkeypair -v -keystore release.jks -alias drunckat \
  -keyalg RSA -keysize 2048 -validity 10000
```

签名文件已在 `.gitignore` 中排除，不会提交。

## 项目结构

```
com.drunkcat.barrier/
├── admin/        Device Owner 管理
├── data/         偏好存储、应用查询、白名单、默认锁定清单
├── risk/         风险评分引擎（6 信号）
├── service/      无障碍监测、前台服务、预警、健康检查
├── track/        轨迹记录、逆地理编码、投影
├── report/       拦截日志
├── verify/       清醒验证（算术/成语/点阵）+ 难度分级
└── ui/           界面（琉璃风 + 简约风双主题）
```
